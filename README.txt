FAVICON — in index.html change these two lines near the top of <head>:
  <link rel="icon" type="image/png" href="...">
  <link rel="apple-touch-icon" href="...">
You can use a path like assets/favicon.png or any image URL.

OG IMAGE — already set to:
  https://raw.githubusercontent.com/Rishit-1010/Stereo/main/Logo.png
Edit og:image and twitter:image meta tags in index.html to change it.
